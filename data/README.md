# Data inputs

The datasets are not redistributed in this repository because their course and third-party redistribution permissions were not established.

## Required for the included Part I script

Place the authorised course copy of:

```text
EEI_TH_P1_2026.dta
```

in this directory. The expected relative path is `data/EEI_TH_P1_2026.dta`.

The source file audited for this reconstruction contained 4,285 observations and these variables:

```text
mark year country K L sales M W exporter FDI nace exp_intensity
VA real_K real_M real_sales real_VA
```

- `EEI_TH_P6_2026.dta`

The explanatory note reports results for Problems VI–VII, but the matching Part II source commands were not present in the available code-listing PDF. The numerous `problem6_*`, map-ready, coordinate, weight, and merged `.dta` files in the working folder are generated intermediates and are intentionally not tracked.

Acquire every input from its authorised provider and comply with its licence, citation, access, and redistribution terms.
